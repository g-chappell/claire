HUMAN:
Requirement ID: 3d2f24cb-REQ
Title: Battleships Web Game
Description:
Overview

Build a simple, browser-only Battleships game where a human player competes against an AI opponent on classic grids. The player should be able to place a fleet, take turns firing at the AI’s hidden board, receive clear hit/miss/sunk feedback, and play through to a clear win or loss via an intuitive mouse/keyboard driven web UI.

Game features (high level)

•	Dual 2D grids for human and AI boards.
•	Fixed fleet of ships for both players (e.g. 5 ships of varying lengths).
•	Human fleet placement with basic validation and a “Randomize Fleet” option.
•	AI fleet automatically placed randomly under the same placement rules.
•	Turn-based play where the human always shoots first, then alternates with the AI.
•	Visual hit/miss markers on both boards that persist for the whole game.
•	Clear indication when individual ships are sunk (e.g. status message).
•	Status text showing whose turn it is and key events (hits, misses, sunk, win/lose).
•	End-of-game state when all ships of one side are sunk (You win / You lose).
•	“New Game” button to reset and start a fresh match without reloading the page.

Technical constraints

The game must run entirely in the browser as a frontend-only implementation (HTML/CSS/JavaScript), with no backend services or external APIs required for core gameplay, and all interaction handled via mouse and/or keyboard input.

Acceptance criterion

The requirement is met if a user can open the app in a modern browser and play a complete Battleships match against the AI, from fleet placement to a win or loss outcome, using only the UI, with all listed features working as described.
